# Python Command-Line Calculator

A simple, interactive command-line calculator written in Python. It supports basic arithmetic operations, exponentiation, and modulo calculations with input validation and zero-division error handling.

---

## Features

- **Standard Arithmetic:** Addition, Subtraction, Multiplication, Division
- **Advanced Operations:** Exponents ($x^y$) and Modulo ($x \pmod y$)
- **Input Validation:** Prevents crashes from invalid (non-numeric) inputs
- **Error Handling:** Safely handles division by zero
- **Interactive Loop:** Perform multiple calculations in a single session until manually exiting

---

## Requirements

- Python 3.x installed on your machine.
